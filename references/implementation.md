# 工程与导演台适配

## 使用通用空骨架

从 skill 目录执行（用真实的绝对路径替换示例路径）：

```sh
python3 scripts/new_project.py /目标路径/新视频工程 --title '视频名称'
```

目标目录必须不存在。复制后首先完成 `reference.md`，再从零搭建场景。`project.json` 的 `template: true` 表示还是未改编的空骨架；完成搭建和验证后改为 false，常规录制才可运行。

复制到的是**通用空骨架**：渲染器、场景、相机、材质工厂（`MAT`）、几何工具（box / ball / limb）、人形骨架工厂（`makeFigure`）、灯光，以及一块灰地面和网格；`actors` / `objects` / `hands` 是空注册表，`updateAll(t)` 为空实现。它没有任何人物、道具或剧情，每次新任务都从零生成全新场景，不能只修改标题就当作另一个故事交付。Three.js、fflate 与 MP4 封装库文件及许可证随包附带，不依赖原电脑目录或 CDN。想参考一套完整工程时看 `examples/校园之旅/`。

## 目录与入口

- `reference.md`：用户可读的剧情、编号、时间与镜头约定。
- `project.json`：工程唯一身份、标题、fps、宽高及骨架标识（`template`）。
- `white-model/world.js`：通用引擎骨架 + 空场景；新任务在这里搭建空间、人物与动画。
- `white-model/director-catalog.js`：S 时间表、人物／道具／关节注册表；空骨架只有一个占位 S。
- `white-model/collision.js`：实体复合体积、SAT、关节接缝、编辑扫掠和原动画验证。
- `white-model/director-model.js`：目标状态、绑定、关节、导入校验和对象操作；无 P01 时自动跳过定位身体与前景手相关逻辑。
- `white-model/director.js`、`.html`、`.css`：导演台界面与交互；时长、时间轴上限与默认选中对象按工程内容自适应。
- `white-model/project-runtime.js`：读取工程配置。
- `white-model/timeline.js`：故事时钟／播放时钟转换与总时长；空骨架为恒等转换，新剧情同步适配。
- `white-model/vendor/mp4-muxer.mjs`：浏览器 WebCodecs 输出的本地 MP4 封装库。
- `scripts/launch_preview.py`：本地 HTTP 服务与打开页面，自动分配空闲端口。
- `scripts/record_white_model.py`：确定性逐帧录制与关键帧导出。

三个 command 使用自身目录定位工程，优先使用工程 `.venv/bin/python`，否则使用 PATH 中的 python3。预览服务在终端前台运行，Ctrl+C 停止；每次启动使用独立空闲端口，不会打开另一个故事。

## 新故事必须适配的内容

配置中的工程身份、fps、导演台时长、时间轴上限、默认选中对象和导出校验已抽取为动态值；**剧情、模型结构与镜头逻辑需要你从零搭建**。

| 位置 | 需要做的工作 |
|---|---|
| world.js | 搭建空间、人物／动物／车辆与道具；把对象分别注册到 `actors` / `objects` / `hands`；在 `updateAll(t)` 里按绝对时间 t 驱动全部运动与剧情镜头 |
| director-catalog.js | 定义全部 S 时段（单段 ≤20 秒、连续覆盖整片）与人物／道具／关节注册表；空骨架的占位 S01 会整段替换 |
| timeline.js | 按剧情设定 DURATION 与故事／播放时钟映射；简单剧情保持恒等转换，并按帧对齐时长 |
| director-model.js 构造器 | 无 P01 时不会创建定位身体，标签自动兜底；如需定位身体、固定人形部位、墙体识别或碰撞物列表，按本片对象补齐 |
| collision.js / 动画验收 | 所有实体及真实骨架部位必须有覆盖实际体积的碰撞体；复杂资产和高速运动需扩展检测；搭建过程中产生的重叠必须修正后才能生成视频 |
| IK 与警告 | 人形臂长、地面高度、可交互道具；动物和车辆使用适合的结构与控制 |
| director.js draw / sync | 第一人称隐藏实际主角身体、显示定位身体；无人故事不隐藏任何东西。默认选中取消后落到第一个已登记对象 |
| director.js 场景跳转 | 跳 S 时自动选中第一个对象并聚焦；观察机位由场景包围盒推导，无需写死坐标 |
| director.html / 导出说明 | 只保留通用文案（标题、第一人称字样、时长标签由初始化后动态覆盖） |
| sourceHash | 若新增动画或模型代码文件，加入版本摘要；二进制资产也应纳入版本标识或资产清单摘要 |

时长、时间轴上限与时长标签在初始化时按 `world.duration` 自动写入，静态 HTML 不再保留任何旧秒数。新剧情改编后无需手动改这些数字。

建议把复杂故事的数据集中到一个场景注册模块，由 reference 和导演台共用编号。是否进一步重构由任务复杂度决定，不必为短片建立完整动画软件。

## 场景与录制接口

播放页提供：

```js
window.__wm = {
  ready: true,       // 资源与场景完全就绪后才设 true
  duration: 12,      // 实际总秒数；应与帧率对齐
  seek(t) { /* 计算绝对时间 t 的全部状态并立即渲染 */ }
};
```

可保留 snapshot / probe 用于检查。`?mode=seek` 下禁止自动推进时间。所有对象位置、姿态、可见性、绑定状态、灯光及镜头都由 t 决定；不能依赖“之前播放到哪一帧”。需要随机效果时固定种子或预计算。

`createWhiteWorld` 返回共用的 scene、camera、renderer、duration、actors、objects、hands、environmentGroups、evaluate 等。若重组接口，同时更新导演台；缺失对象必须从注册表和操作界面移除。不可用空壳对象掩盖异常。

一镜到底保证相邻 S 的位置、朝向和运动节奏连续。多镜头通过明确的剪辑时间选择镜头状态，切点不做意外插值；必要时重建空间或切换空间可见性。观察镜头不是剧情镜头。

首人称身体、独立前景手与剧情镜头保持独立编辑；修改动画时核对身体和手物接触的一致性。第三人称或无主角故事不应凭空创建一个必选主角身体。

## 目标状态与静态道具固定

普通姿态修改只有点击保存时间点后才进入目标列表；回放不自动插入目标状态。ZIP 中保留完整原状态、目标状态、编辑值、坐标单位、fps、帧号、S 编号、工程身份和版本。

空骨架自带静态道具固定机制：原动画中不走位且未绑定的物体及复制组件被移动后，通过 `overrides` 从当前帧持续到片尾，可显式解除固定。这与人物关键姿态的手动保存是两种行为。

新故事若保留该功能，必须在界面与说明中讲清楚固定范围，导出／导入时保留 overrides，录制时把用户接受的固定变化写回世界动画；不能以为导演台 overrides 已经自动写入播放页。若不需要，完整移除相关界面、模型和包字段，而不是留一半。

静态道具识别用的 isStatic 每秒采样可能漏掉短暂移动。新故事优先在对象注册数据中明确声明静态／动态属性；不能把采样结果当作所有对象的可靠物理分类。

不同工程身份、fps、时长、sourceHash 的状态包默认拒绝导入。需要旧包迁移时先建立明确的编号和变换映射，再生成兼容包；不要关闭校验或继承任何历史哈希白名单。

## 导演台交互与片段录制

暗色界面保留选中轮廓与聚焦剖切；轮廓、编号、操作工具和对照模型不混入出片。镜头键位、速度设置、Shift 加速与两种录制入口遵循 SKILL.md 的关键交互要求。普通编辑时聚焦视角临时隐藏遮挡物；第三人称录制实时画面与逐帧重渲染均关闭自动避挡，结束后恢复原视角。快退／快进按钮按 5 秒跳转。坐标字段、吸附与无人机面板已从当前界面移除，不要在搭建新工程时重新加入；移动／旋转通过上方按钮选择。

Enter 在走位说明中显式保存，Shift+Enter 换行；保存同一帧更新目标、视角与固定段快照。书签节点在定时刷新中保留，避免慢点击或键盘焦点丢失。删除当前书签回退本帧编辑和固定段；未保存变化不进入导出的 states。

副本来自可选整体对象（人物、道具、独立前景手或剧情镜头），用同类前缀顺延编号。副本不复制动画，注册到组件列表，可填备注、移动、固定及删除；关节与未注册建筑不单独复制。`components` 记录来源、编号、世界矩阵、创建帧和备注，`复制记录.md` 提供用户可读记录。导入按来源依赖恢复副本，拒绝循环来源、无效变换或穿模副本；失败还原先前工作状态。

浏览器的剧情录制输出 C01；第三人称录制保存观察相机的 position、quaternion、fov、aspect、near、far 与时间，并在编码时按帧插值重放。生成期间锁定操作，失败和不足一帧也须解除锁定并恢复起点。分辨率和帧率取自 `PROJECT.width`、`PROJECT.height` 和 `FPS`；WebCodecs 配置及 MP4 封装保持一致，第三人称完整画幅适配输出并加黑边。文件名包含起止秒数，输出静音 H.264。浏览器不支持 H.264 时报告限制，仍保留工程与终端录制入口。

空骨架导演台采用 `new DirectorModel(world,{liveCollision:false})`，编辑、复制、保存与导入导出不执行碰撞扫描；浏览器录制是自由编辑的预演记录。终端正式视频生成执行全片与帧间检查，失败中止编码。旧包迁移必须按对应工程编写映射，新工程不能继承校园专用哈希白名单或以 `migratedFrom` 绕过生成验收。

## 体积碰撞

执行 [体积碰撞约束](collision.md)。导演台自由编辑不扫描碰撞；生成／改写正式动画时检查完整实体与帧间路径，发现穿透先修正，再生成正式 MP4。旧工程已有碰撞须如实报告，不能把自由编辑的录屏当作无穿模验收结果。

## 运行和录制

预览只需 Python 3 和支持 WebGL 的浏览器。录制使用 Python 包 playwright、av、Pillow 及 Playwright Chromium。先检测现有环境；缺少时在工程 `.venv` 中安装，不改全局 Python：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install playwright av Pillow
.venv/bin/python -m playwright install chromium
```

使用实际可用的解释器运行：

```sh
python3 scripts/launch_preview.py --page director.html
python3 scripts/record_white_model.py --preview --name 白模预演-v01
python3 scripts/record_white_model.py --name 白模预演-v01
```

`--frames 3 --allow-template` 仅供空骨架冒烟验证，输出标记为 partial，不能作为完整成片交付。默认完整录制为 duration×fps 帧，采样 t=0 至 duration−1/fps；最终定格须在最后一段留出可见时间，t=duration 也单独输出关键帧。

录制脚本自动导出各段中点及首末关键帧；另按剧情补充动作接触点、转场两侧等诊断图片。脚本拒绝覆盖同名 MP4，使用新版本名。录制信息记录真实帧数和时长，音轨为空。

## 验证重点

- 所有实体的体积、姿态与运动通过碰撞检查，报告为 `ok: true`；关节、绑定道具、门扇、高速运动及帧间路径均覆盖。
- 新故事的全部 S 时段连续、有序、每段 ≤20 秒，末段结束等于实际 duration；fps 与导演台及录制配置一致。
- 正向、逆向、随机 seek 得到相同状态，加载完成前不开始录制。
- 故事镜头画面无编辑器控件、标签或调试文字；不同视角和编号命名正确。
- 两个目标时间点的编辑、保存、导出、重载导入可准确恢复；固定段快照、副本来源／编号／备注与观察视角准确；撤销重做、绑定解除与错误工程／fps／时长／版本拒绝正常。
- 浏览器两种录制视角正确，第三人称运镜可重放且无自动避挡；对象编辑锁定，结束／失败后恢复起点和按钮。正式原动画碰撞验收失败时不生成成片。
- 同一人物不存在错误重复身体；无人故事、动物或车辆不因缺 P01 人形骨架而报错。
- MP4 全片可解码，帧数和时长正确；先少量关键帧检视，再完整录制。

用新的故事内容进行后续验收；空骨架可运行只证明复用资源与工具链可用，不能证明任意题材已实现。

复用验证：`python3 scripts/check_director_ui.py /工程目录`（从新工程中运行），以及 `node scripts/check_volume_collision.mjs`。
