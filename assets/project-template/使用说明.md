# 白模工程

双击“启动白模预演.command”查看剧情；双击“启动导演工作台.command”编辑目标状态。启动窗口提供本机服务，按 Ctrl+C 停止。

在导演台选择 S 片段和时间，调整对象，填写走位说明，再点击保存时间点。下载修改包后交给助手改写连续动画。目标姿态不会自动成为新动画。

静态道具的“固定到片尾”与保存人物目标姿态不同；解除固定可恢复原位置。助手应将采用的固定变化同步到正式动画。

完整录制使用“导出白模视频.command”。输出在 deliverables 中，包含 MP4、关键帧及录制信息。已有同名视频不会覆盖；终端可使用 `python3 scripts/record_white_model.py --name 白模预演-v02` 导出新版本。

当前复制物是通用空骨架：一块灰地面、网格和灯光，没有人物、道具和剧情。助手须按新剧情填写 reference.md、在 world.js 搭建空间与人物、在 director-catalog.js 注册编号与 S 时间、把时间轴 DURATION 与新剧情对齐，再将 project.json 的 template 改为 false。预览可先启动确认骨架正常，完整录制在完成改编后启用。

录制需要 Python 3、playwright、av、Pillow 与 Chromium。工程 .venv 如已配置会被 command 优先使用。

## 导演台与生成验收

导演台自由摆放目标，不在拖动、旋转、关节、复制或保存时扫描碰撞；非法坐标、零尺寸与循环绑定仍拒绝。正式动画生成前检查全部模型体积与帧间路径，失败不输出正式视频。

WASD 水平移动，↑↓ 升降，←→ 转向；I/K 上下看、J/L 逆／顺时针侧倾；Shift 将手动平移与升降加速 3 倍。齿轮可设置各项速度并在本机保存。Enter 保存时间点，Shift+Enter 换行；支持副本、备注、删除、撤销重做与修改包。

“录制”输出 C01；“第三人称录制”支持键盘与鼠标运镜，关闭自动避挡但保留手动隐藏墙体／天花板。停止后按帧重放并导出静音 H.264 MP4，完整画幅必要时加黑边，结束或失败后恢复起点。

详细操作见 `white-model/导演工作台使用说明.md`。
